## 1. 逆算のツリー

```
【最終ゴール】福岡市で「女性用風俗」検索 → 1位
     │  必要条件 = ①テーマの専門性 × ②地域との結びつき
     │
     ├─【中間ゴール】「女風 福岡」3位以内 → 1位（現在5位）
     │   │  残っている差 = 鮮度の持続 / 被リンク / 口コミ量
     │   │  （オンページは競合と同等以上まで到達済み・7/30時点）
     │   │
     │   └─ この記事の寄与 ①鮮度シグナル ②トピック網羅性 ③滞在時間
     │
     └─【小ゴール】セラピスト名の指名検索の受け皿
         └─ この記事の寄与 ④「セイラ」指名KWの受け皿 ⑤内部リンクで店舗ページへ集約
```

**この記事が担当するのは、上の①〜⑤です。**「女風 福岡」で直接1位を取る記事ではありません。そこは店舗トップの仕事で、この記事はそれを支える側です。この役割分担を混同すると、記事タイトルにビッグKWを詰め込んで店舗トップとカニバる事故が起きます。

## 2. 縄張り判定 — なぜ /amolab ではなく /store/fukuoka 配下なのか

共通プロンプトの縄張りルールに照らすと:

| 候補 | 判定 | 理由 |
|---|---|---|
| `/amolab` 配下 | ✗ | アモラボは非地域KW担当で「titleに地域名を入れない」。この記事は福岡・博多・アビスパ福岡・博多ラーメンと地域情報が骨格。地域名を抜くと記事が成立しない |
| `/store/fukuoka` 配下 | ✓ | 地域KW担当。エリア名を含むコンテンツはここ、という定義そのまま |
| `/recruit` 配下 | ✗ | 顧客向け記事。求人要素を露出させない（ただし後述の「もったいない点」参照） |

→ **正規URL = `https://www.sutoroberrys.jp/store/fukuoka/interview/{castId}/seira-interview-vol4`**

sitemap.ts が出力しているのもこのURLなので、実装との整合も取れています。

### ここで見つかった構造的な問題（要修正）

同一記事が**3つのルートで描画される**実装になっていました。

| ルート | 現在のcanonical | 判定 |
|---|---|---|
| `/store/[slug]/interview/[cast]/[article]` | 自分自身 | ✓ これを正規にする |
| `/store/[slug]/cast/[cast]/interview/[article]` | 自分自身 | ✗ 重複。正規URLを指すべき |
| `/magazine/interview/[slug]` | **設定なし** | ✗ 重複。正規URLを指すべき |

鉄則2「1記事1URL」に正面から違反しています。既存3本（サイ／カズヤ／ユウヒ）も同じ状態です。実装パッケージの「作業3」で一括修正する設計にしました。URL自体は変えず、canonicalの付け替えのみ（URL変更禁止の方針を守るため）。

### 「福岡」を seo_title に入れた理由

過去のサイvol.1は title に「福岡」も「女性用風俗」も入っていませんでした（interview_kiji メモの指摘どおり）。店舗ページ配下＝地域KW担当の記事なのに、地域宣言がタイトルにないのはもったいない。今回は入れています。

一方で「女性用風俗」という語は**タイトルに入れていません**。理由は、店舗トップ（`/store/fukuoka`）が「女性用風俗 福岡」の本命ページであり、インタビュー記事が同じ語で並ぶとカニバリのリスクがあるためです。記事側は本文・FAQ・seo_description に自然に含める形にとどめました。

## 4. 素材の中で「SEO的に一番強い」もの

取材素材を価値順に並べると、こうなります。

| 順位 | 素材 | なぜ強いか |
|---|---|---|
| 1 | **「もう35ですし、最後のチャンスかなと思って」** | 読者（初めての利用を迷っている人）と鏡像の物語。滞在時間・読了率・記憶残存に効く。タイトルに採用 |
| 2 | **7〜8年の全身脱毛／「肌のつるつるさは負けません」** | 検証可能で具体的な「投資の証拠」。抽象的な「清潔感アピール」と決定的に違う |
| 3 | **「好きになった人には好かれないんですよ」** | 予想外の弱さ。完璧なプロフィールより信頼を作る。E-E-A-Tの「経験」の質感 |
| 4 | **博多ラーメン3軒（一双・しんしん・ふくちゃん）** | 唯一の**地域固有・固有名詞**の資産。ローカル文脈を最も強く出す素材 |
| 5 | **アビスパ福岡ファンクラブ・ゴルフ場で朝8時から酒** | 生活の手触り。地域性の裏づけ |
| 6 | 「気配り・心配りは部活で習った」 | 接客への接続。ただしよくある表現なので単体では弱い |

**「気配り」だけで記事を作ると、他店のプロフィール文と区別がつかなくなります。** 1〜4を骨格にして、6を接着剤として使う構成にしました。

## 6. この記事が「まだ回収できていない」もの — 次の一手

### (A) リクルート導線がゼロ

interview_kiji メモの指摘どおり、既存インタビュー4本すべてで求人導線がありません。セイラさんの取材内容は**そのまま求人コンテンツとして極めて強い**です。

- 「話題になった頃から知っていたが、なかなか踏み出せなかった」
- 「35歳、最後のチャンスかなと思って応募した」
- 「ホームページが柔らかい感じで、ちゃんとしたお店だと思った」（＝応募者の店舗選定理由の一次情報）
- 「決まりごとを覚えられるか不安だった」（＝応募検討者の最大の不安）
- 「LINEも丁寧に細かいところまで教えてくれる」（＝サポート体制の証言）

縄張りルール上、顧客向け記事に求人要素は出せません。**別記事として `/recruit` 配下に作るのが正解です。**

> 提案タイトル例: 「35歳から始めた男性求人 — 福岡で女性用風俗セラピストに応募したセイラの話」
> （鉄則: titleに「求人」を含む／顧客KWを狙わない／顧客ページから求人へのリンクは張らない）

同じ取材から2記事は「1記事1テーマ」に反しません。**切り口とURLとターゲットKWが完全に別**だからです。ただし本文の使い回しはしないこと。

### (B) ラーメン資産の回収

「一双・しんしん・ふくちゃんラーメン」は、地域文脈を作る素材として現状かなり過小利用です。ただし単発でラーメン記事を作っても検索意図が女性用風俗と噛み合いません。

現実的な回収先は**写メ日記**です。取材の最後にご本人へ伝えたとおり、日記はドメイン上に残る資産で、SNSと違って凍結リスクがありません。「福岡出張で使えるラーメン」のような日記シリーズは、鮮度シグナル（週3更新の目標）と地域文脈を同時に稼げます。

### (C) 実務フリクション（料金・時間・バレ）の情報がない

めぐ回のフィードバックで最も低かった項目（30/100）です。今回のセイラ取材でもここは踏み込めていません。読者が本当に知りたい「いくらかかるのか」「どのくらいの時間か」「バレないのか」は、記事末尾の内部リンク（料金／初めての方へ）に受け渡す設計にしましたが、記事本文で触れられるとより強くなります。→ 第2弾の質問リストに入れています。

## 7. 効果測定（2週間後・4週間後）

計測ルールは既存方針に従います（デプロイ15分後×3回の中央値、対象URL固定）。

| タイミング | 見る指標 | 合格ライン |
|---|---|---|
| 公開直後 | GSC URL検査 → インデックス登録 | 3日以内にインデックス済み |
| 2週間後 | 「セイラ」関連KWの表示回数 | 0 → 立ち上がっていること |
| 2週間後 | 記事URLの平均掲載順位 | 「セイラ ストロベリーボーイズ」で10位以内 |
| 4週間後 | 記事からの内部リンククリック（GA4） | 出勤スケジュール／料金へのクリックが発生 |
| 4週間後 | `/store/fukuoka` の平均順位 | 悪化していないこと（カニバリの有無を確認） |

**最後の1行が重要です。** インタビュー記事が店舗トップの順位を食っていないかは、記事を増やすほど確認が必要になります。

## 8. 次の記事に引き継ぐ型（テンプレ化）

このやり方は他のキャストにもそのまま使えます。

1. 取材素材を「①検証可能な具体性 ②予想外の弱さ ③地域固有名詞 ④読者との鏡像性」の4軸で棚卸しする
2. ①〜④が最も強い素材をタイトルに置く（役職・肩書きではなく**言葉**を置く）
3. 縄張り判定 → 店舗配下かアモラボかを先に決める（後から動かすとURL変更になる）
4. seo_title に地域名を入れる／ビッグKWそのものは入れない
5. FAQ 3問は「初めての不安」「地域で何ができるか」「このキャスト固有の懸念」で固定する
6. 末尾は内部リンク3本（出勤スケジュール／料金／初めての方へ）で締める
7. 同じ取材から求人記事を1本切り出せないか必ず検討する
