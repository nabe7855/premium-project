## 2. 記事の性質（作業判断の前提）

- 実在のお客様（仮名「あや」さん・30代・既婚）への**インタビューに基づく一人称の体験談**です。

## 3. 絶対にやってはいけないこと（MUST NOT）

1. **本文テキストの改変禁止。** 言い回しの言い換え、要約、誤字と思われる箇所の「修正」も一切しない。口語・言いよどみは意図的なものです。
2. **段落の結合禁止。** 1段落40〜80字・`<br>` を含む短い改行構造は、スマホでの可読性のために設計されたものです。CMSやフォーマッタで `<p>` をまとめたり `<br>` を削除したりしないこと。
3. **目次（TOC）を追加しない。** 物語の流れを切り、飛ばし読みを誘発するため、意図的に外しています。
4. **画像内の文字をテキスト化しない／漫画コマの順序を変えない。**
5. **`Review` / `AggregateRating` の構造化データを追加しない。**（自社サイト上の自己申告レビューはGoogleのポリシー上不可）
6. **仮名「あや」を実名や別名に変えない。**
7. **表現の変更禁止。** 直接的な性的表現は意図的に排しています。「女性専用リラクゼーション」「寄り添い」「セルフケア」の文脈を維持すること。

### 4-2. 冒頭の編集用注記を削除
`<div class="editor-note">…</div>` は社内確認用です。**本番では必ず削除**してください（CSSの `.editor-note` も不要なら削除可）。

### 4-3. プレースホルダの差し替え（全て必須）

| 箇所 | 現在の値 | やること |
|---|---|---|
| `<link rel="canonical">`（8行目付近） | コメントアウト状態 | **コメントを外し**、本番URLを設定 |
| JSON-LD `publisher.logo.url` | `https://（本番ドメイン）/logo.png` | 実際のロゴURL（絶対URL） |
| JSON-LD `image` | `https://（本番ドメイン）/voice/aya/images/aya-photo-top.webp` | 実際の絶対URL |
| JSON-LD `mainEntityOfPage.@id` | `https://（本番ドメイン）/voice/aya/` | 実際の記事URL |
| `og:image` | 相対パス `images/aya-photo-top.webp` | **絶対URL**に変更（相対だとSNSで表示されない） |
| `datePublished` / `dateModified` | `2026-07-27` | 実際の公開日（ISO 8601） |

### 4-4. 内部リンクの設定（`href="#"` を実URLに）

以下5箇所すべて。アンカーテキストは**変更しないこと**（キーワードを含む設計になっています）。

1. CTAボタン「初めての方へ（安心ガイド）を見る」→ 初めての方向けページ
2. FAQ内「当日の流れ」→ サービス説明／流れのページ
3. 関連記事「はじめての女性用風俗｜当日の流れ・料金・不安への答え」→ 該当記事
4. 関連記事「料金・コース一覧｜初回におすすめのプラン」→ 料金ページ
5. 関連記事「利用者インタビュー一覧」→ 一覧ページ（未作成ならCTAと同じ導線でも可）

※ `href="#cta-first"` はページ内アンカーです。**そのまま維持**してください。
※ CTA下の `<span class="micro">※ リンク先は…差し替えてください</span>` は作業指示なので、**設定後に削除**してください。

### 4-5. 既存サイトへの組み込み方針
- サイト共通のヘッダー／フッター／パンくずの中に、記事本文（`<body>` 内の `.hero` と `.wrap`）を挿入する形にしてください。
- **CSSの衝突に注意。** サイト共通CSSが `p` や `img` に余白・枠線・影を当てている場合、この記事の設計（余白で読ませる／画像は角丸のみ）が崩れます。必要なら記事全体を `.article-aya` などでスコープして、この記事のCSSを優先させてください。
- Google Fonts（Noto Sans JP）を読み込んでいます。サイト側で既に日本語フォントを指定している場合は、**この記事の指定を優先**させてください。
- パンくずを設置する場合は `BreadcrumbList` の構造化データも追加してよい（既存の2つのJSON-LDは維持）。

### 4-6. 画像の扱い
- 9点はすべて **WebP・最適化済み**です。**再圧縮・リサイズ・形式変換は不要**（劣化するため避ける）。
- CMSが自動でリサイズ／WebP再変換する場合は、**この記事だけ除外**してください。
- `width` / `height` 属性は CLS（レイアウトずれ）防止のため必須。**削除しないこと。**
- トップ画像は `fetchpriority="high"`、以降は `loading="lazy"`。この指定を維持してください。
