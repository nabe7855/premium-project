# めぐさん記事 漫画化｜画像生成プロンプト集（やわらかい少女漫画風）

> 対象：「このままおばあさんになりたくなかった」めぐさんインタビュー記事
> 用途：記事内の“要所シーン”に差し込む漫画コマを、画像生成AI（ChatGPT画像 / nano-banana / Midjourney 等）で作るためのプロンプト集
> テイスト：やわらかい少女漫画風（繊細な線・淡い色・キラ／花エフェクト・エモーショナル）

---

## ⭐ 最初に読む：うまく作る5つのコツ

1. **文字は「空の吹き出し」で生成し、日本語は後から載せる。**
   画像生成AIは日本語テキストをほぼ正しく描けません（文字化けします）。各プロンプトは「空の吹き出し（テキストなし）」で生成する指示にしています。**セリフは各コマの「載せる文字」欄をCanva / Photoshop / Clip Studio / PowerPointなどで後入れ**してください。これが仕上がりの差になります。

2. **毎回「共通設定ブロック」を先頭に貼る。**
   下の【共通ブロック】をコピーして、各コマのプロンプトの前にくっつけて生成すると、絵柄とキャラの見た目がそろいます。

3. **キャラは“実在しない一般的な30代女性”。**
   これは実在のお客様の物語です。特定の人に似せないでください（=匿名配慮）。生成AIは自動で架空の顔を作りますが、念のためネガティブに「実在の人物・有名人に似せない」を入れています。

4. **コンプラ：性的な直接描写はしない。**
   訴求は「癒やし・寄り添い・自己肯定感」。CHAPTER04も“かわいいと言われて心が動く”感情描写にとどめ、性的表現は入れません（ネガティブにも明記）。

5. **一貫性を保つ運用。**
   - ChatGPT画像なら：1枚目を作った後「**同じキャラ・同じ絵柄で、次のシーンを**」と続けて指示。
   - Midjourney等なら：`--seed` を固定＋1枚目を参照画像（`--cref` / image prompt）に。
   - どのツールでも【共通ブロック】を毎回貼るのが基本。

## 🔧 一貫性を保つ運用メモ（ツール別）
- **ChatGPT画像 / nano-banana：** 最初の1枚が良ければ、その画像を添付して「このキャラ・この絵柄のまま、次は『◯◯のシーン』を作って」と続ける。顔や髪型がブレたら「1枚目と同じ顔・同じ髪型で」と明示。
- **Midjourney：** 1枚目で気に入ったものの `--seed` を控える → 以降 `--seed 同値` ＋ キャラ参照 `--cref <1枚目URL>` ＋ `--sref <1枚目URL>`（絵柄参照）。比率は `--ar 16:9` / `--ar 4:5` / `--ar 1:1`。
- **共通：** 【共通ブロック】は毎回必ず先頭に。髪型は「序盤＝ショート／終盤＝伸ばし始め」の指定を守るとBefore→Afterの物語が絵でも通る。

## ✍️ セリフ（日本語）の載せ方
1. 空の吹き出しで画像を生成。
2. Canva / Photoshop / Clip Studio / PowerPoint / Figma で開く。
3. 吹き出しの上に日本語テキストを配置（少女漫画は明朝系＋手書き風のミックスが雰囲気◎）。
4. モノローグは吹き出しなしで余白に、セリフは吹き出し内に。
5. 画像はWebPで書き出し、記事のalt・ファイル名は英数KW（例 `megu-manga-press-button.webp`）で。
