# めぐさん 一人称記事（v3）｜漫画の構図＆画像生成プロンプト集

> 対象：「めぐ_インタビュー記事_v3_一人称.html」に差し込む漫画
> 前提：**キャラクターデータ（めぐのキャラデザ）はすでに作成済み** → 各プロンプトは「そのキャラを参照させて、構図・表情・場面だけ指定する」形にしています。
> テイスト：やわらかい少女漫画風（前回と統一）。一人称記事なので、セリフは基本すべて**「私」＝めぐのモノローグ**。

---

## ⭐ 使い方（3ステップ）

1. **毎回、作成したキャラクター画像を"参照"として渡す**（ChatGPT画像／nano-banana なら添付、Midjourney なら `--cref`）。顔・髪型・服の系統は参照に合わせて統一。
2. 下の【共通プレフィックス】＋各コマの【構図＆プロンプト】を貼って生成。
3. **吹き出しは"空"で生成 → 日本語のセリフは後からCanva等で載せる**（画像生成AIは日本語文字が崩れるため）。

> 髪の"変化"演出：物語上、序盤（P2〜P4）は短め／終盤（P6）は伸ばし始め、にできると「変わっていく感じ」が絵でも伝わります。キャラデザが固定なら、無理せず"表情と明るさ"で変化を出せばOK。

## P1｜ヒーロー：予約ページの前で止まる夜　＜16:9＞
**記事の位置：** 冒頭ヒーロー ／ **役割：** 3秒で「これは私の話かも」

- **構図：** 引き〜ミドル。夜の部屋、手前のソファに座るめぐを斜め後ろ〜横から。スマホの画面の光だけが顔を照らす。予約ボタンの手前で止まる指先。**右側を大きく空ける**（タイトル・テキスト用）。
- **アングル：** ややローで、孤独感と静けさ。
- **表情：** ためらい＋好奇心。
- **アスペクト比：** 16:9

**プロンプト（日本語）：**
```
（共通プレフィックス）＋
夜の部屋。めぐがソファに座り、スマホの予約ボタンの手前で指を止めている。画面の光が顔をやさしく照らす。
斜め後ろ〜横からのミドルショット、ややローアングル。静かでせつない空気、淡い青とピンクの光。
右側に大きく余白（後で文字を入れる）。16:9。
```
**載せる文字（任意）：** なし推奨（記事タイトルが乗るため）／入れるなら小さく「――そのボタンが、いちばん重かった。」

## P3｜止まった指（ためらい）　＜1:1 or 4:5＞ ※任意追加
**記事の位置：** CHAPTER02（半年、押せなかった） ／ **役割：** 不安な読者の最大の共感点

- **構図：** **手元のクローズアップ**。スマホの「予約する」ボタンの上で止まった指。指先が少し浮いて、ためらうように震える。画面の光が指を照らす。
- **アングル：** 手元の俯瞰ぎみ。
- **表情：** （顔は入れず手で語る）迷い・緊張。
- **アスペクト比：** 1:1

- **アングル：** 正面〜やや寄り。めぐの表情が主役。

## 🔧 キャラ一貫性のコツ（ツール別）
- **ChatGPT画像 / nano-banana：** 毎回キャラ画像を添付し「このキャラのまま、次は"○○の場面"を」。ブレたら「参照と同じ顔・同じ髪型で」と明示。
- **Midjourney：** キャラ参照 `--cref <URL>` ＋ 画風参照 `--sref <URL>`、比率は `--ar 16:9 / 4:5 / 1:1`。
- **セリフ：** 空吹き出しで生成 → Canva/Clip Studio 等で日本語を後入れ。モノローグは吹き出しなしで余白に置くと少女漫画っぽい。書き出しは WebP、ファイル名は英数KW（例 `megu-press-button.webp`）。
